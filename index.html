GOOD TO KNOW

A few quick answers.

Is OrbitFX Studio free to try?

This beta is provided as a direct download, with no sign-up or payment step on this page. No paid plans are offered here.

Do I need to install anything?

To use the version hosted on this website, no installer is needed. For the downloadable local version, extract the ZIP and run the supplied Windows launcher with Node.js LTS installed.

Can I use it in OBS?

Yes. Export a clean OBS scene from the editor, then add the exported page as an OBS Browser Source. The guide explains how to keep the files together.

Will it access my camera automatically?

No. The public release starts with a generated test feed. Webcam permission is requested only when you select and connect your webcam. VDO.Ninja sources must be connected separately.

Will my project stay saved?

The editor autosaves in your browser, but that can be cleared. Export a project JSON file to keep a portable backup, especially before changing computers or browsers.

Can I use it with a VTuber model?

Yes. Feed your live model from a supported source such as VDO.Ninja or a webcam/virtual-camera setup. You may need chroma keying to remove its background.
