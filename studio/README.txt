ORBITFX STUDIO · BETA V3
by Portal Master Of Games

A browser-based scene and visual-effects editor for live creators.

QUICK START (WINDOWS — LOCAL)
1. Extract ALL files from this ZIP into a folder.
2. Install Node.js LTS from https://nodejs.org if you do not have it.
3. Double-click START-STUDIO.cmd. Keep the terminal window open.
4. Open http://127.0.0.1:8787/content.html in Chrome or Edge.
5. The public beta starts with a generated test model (no remote stream or camera connection).
6. For your own VDO.Ninja feed, select VDO.Ninja model under Scene, paste your
   own stream ID/view URL, then click Connect source.
7. For OBS setup and project export, open OBS-GUIDE.txt.

QUICK START (WEBSITE)
Upload this ENTIRE folder to an HTTPS web host and open content.html. Your
website can also link to this editor. Do not double-click the HTML using file://;
browser security can block local media, SDK, storage, and export features.

FEATURES
- 0–36 individually adjustable media cards, shared ring / helix / wave orbit
- Full-rotation / left-right swing, tilt, depth, size, direction and speed
- PNG, JPG, WebP and animated GIF; media cards and text/sticker layers
- Green/blue/custom chroma key and model/card glow
- Presets including Arcane, Cosmic, Celebration, Snowfall and Clean
- Backgrounds, particle effects, confetti, clean UI (H), animation pause (Space)
- Local browser autosave, project JSON import/export, clean OBS scene export
- Optional VDO.Ninja remote feed or webcam (permission only after Connect)

IMPORTANT: A saved JSON project carries your content and settings. A clean OBS
scene export embeds the project and images. Do not publicly share exported
scenes or projects containing private media or private stream IDs.

The supplied artwork belongs to its creator. The included VDO.Ninja SDK is
third-party software; see THIRD-PARTY-NOTICES.txt.

LIMITS AND KNOWN BETA NOTES
- Images <=4MB; movie uploads <=12MB; project budget 24MB.
- Animated GIF/movie/live video playback may continue when motion is paused.
- Browser source, camera, and remote video depend on browser/OBS support.
- Existing projects from Studio Pro v2/v3 are supported by the importer.
- Application file size is not a guarantee of low CPU/GPU usage on every PC.
- This public release deliberately does not contain the creator's old
  scene-output HTML or a preconfigured personal VDO.Ninja stream.

SUPPORT: See OBS-GUIDE.txt and the website guide. Beta — features may change.
