OBS & live camera

Save scene-output.html beside this app’s content.html. It includes your project and starts with the UI hidden.

  1. Run START-STUDIO.cmd (Node.js required), or host this folder over HTTPS.
  2. In OBS, add a Browser Source using http://127.0.0.1:8787/scene-output.html. Set 1920 × 1080 and 30 or 60 FPS.
  3. For webcam use, click Start Virtual Camera in OBS, then choose OBS Virtual Camera in your calling app.

A website cannot install a virtual webcam by itself. OBS supplies the camera device. Keep the background solid for calls; transparency is for compositing in OBS.

A copied URL does not transfer browser-saved images/settings to OBS. Use the clean OBS scene download to transfer your complete project.

Shortcuts & capture tips

H hide/show all UI · Space pause motion · B confetti burst. Shortcuts are inactive while typing.

Open ?clean=1 for no controls or cursor. In OBS, right-click the Browser Source → Interact to use the shortcuts.
